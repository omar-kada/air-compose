Notifications

AirCompose sends real-time notifications through Shoutrrr, a unified notification library that supports dozens of services including Slack, Discord, Telegram, Email, Teams, and more.

Configuration​

Notifications are configured in the config.yaml file:

settings:
  notifications:
    notificationURL: "shoutrrr://..."
    notificationTypes:
      - "DEPLOYMENT_STARTED"
      - "DEPLOYMENT_SUCCESS"
      - "DEPLOYMENT_ERROR"
      - "HEALTH_CHANGE"
      - "NEW_COMMIT"
      - "CONFIGURATION_UPDATED"

Notification URL​

The notificationURL field uses Shoutrrr's URL format. Here are common examples:

ServiceExample URL
Telegram Bottelegram://bot{bot_token}/?chatId={chat_id}
Slack Webhookslack://{webhook_id}/{webhook_token}
Discord Webhookdiscord://{webhook_id}/{webhook_token}
Email (SMTP)smtp.{tls_or_ssl}://{user}:{password}@{host}:{port}/?from={from}&to={to}&subject={subject}
Gotifygotify://{host}:{port}/{token}/?title={title}
Webhookwebhook://{host}:{port}/{path}/?method=POST&body={body}

Notification Types​

Select which event types should trigger a notification:

TypeDescription
DEPLOYMENT_STARTEDA deployment process has begun
DEPLOYMENT_SUCCESSA deployment completed successfully
DEPLOYMENT_ERRORA deployment encountered an error
HEALTH_CHANGEContainer health status changed (healthy ↔ unhealthy)
NEW_COMMITNew commits detected in the config repository
CONFIGURATION_UPDATEDConfiguration file was updated
PASSWORD_UPDATEDA user's password was changed
SESSION_REUSEDA revoked refresh token was reused (security event)
MISCMiscellaneous events

Testing​

Use the Test Git Connection button in the Settings page to verify your Git credentials. There is no built-in notification test — instead, trigger a manual sync and check if the notification arrives.

Delivery Flow​

  1. An event is published to the Event Bus
  2. The NotificationEventHandler checks if the event type is enabled in notificationTypes
  3. If enabled and notificationURL is set, Shoutrrr sends the message
  4. The event is also persisted to the Event Store (SQLite) for UI display

If a notification fails to send, the error is logged but does not block the deployment process.
