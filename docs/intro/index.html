Welcome

AirCompose is a lightweight GitOps automation tool that handles Docker Compose stack deployments. Its purpose is to make deploying and updating a self-hosted environment simple, fast, and reproducible — without the need for heavy tooling or dependencies.

Features​

  1. Auto-sync from a Git repository — changes to your compose stacks are detected and deployed automatically
  2. No special syntax — compose stacks keep their original form and are accessible to users
  3. Modern UI — manage everything remotely through a web interface
  4. Notifications — receive alerts on deployments and health status via Shoutrrr
  5. Environment variable overrides — keep secrets local with per-service environment variable management
  6. Self-contained — runs on any Docker-capable system with a mounted Docker socket
